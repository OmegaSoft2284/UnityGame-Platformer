# 🎮 UnityGame-Platformer

**UnityGame-Platformer** is a complete 2D platformer game project built with **Unity** and **C#**.  
This project demonstrates how to design, develop, and structure a side-scrolling platformer from scratch — including player movement, enemies, collectibles, animations, and level design.

Whether you’re a game developer learning Unity or building a base for your own platformer, this project provides a clean, scalable foundation to start from.

## 🚀 Features

- 🧍 Smooth 2D player movement and jumping mechanics  
- 🪜 Platform-based levels with obstacles and collectibles  
- 👾 Enemy AI with basic patrol and attack behavior  
- 🎵 Sound effects and background music support  
- 💾 Checkpoint and respawn system  
- 🎨 Animated sprites and parallax backgrounds  
- 🧱 Modular structure for easy level design and expansion  

---

## 🧩 Technologies Used

- **Game Engine:** Unity 2022+  
- **Language:** C#  
- **Physics:** Unity 2D Rigidbody & Colliders  
- **Animation:** Unity Animator Controller  
- **Audio:** Unity AudioSource and AudioMixer  
- **UI System:** Unity Canvas
